Splits the single wall of my javascript code inside index.html into a set of files inside the "Architecture" folder to document the intended order.

This is documentation only:
- The files are **not** loaded by the game and **not** exported with the rest of this folder
- The actual live code sits entirely inside index.html

The original code is a single wall of text because SugarCube (Twine) takes in JavaScript code from a single text block. Making it a single file avoided load-order bugs and kept the coding process comparatively simple. It was important to me to keep the code simpler as I was creating the characters, the over all narrative, and working out the game design on top of the more technical parts of this project.

The "Architecture" folder exists so I can display what would've been more in-line with my process if I had the time to split the full code into separate files.
