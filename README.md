# TheGreatIllusion

An open-world role playing game built ontop of Twine. Created along with a custom RPG engine.

## **[The Great Illusion: Narrative & Game Design Retrospective](https://github.com/AbeSafi/TheGreatIllusion/blob/main/docs/TheGreatIllusionRetrospective.pdf)**
A 25-page deep dive into the design and narrative architecture of my open-world RPG engine, built by pushing Twine far beyond its intended limits. This document covers player psychology, systems design, branching narrative structures, and the hindsight of building this game around its themes & messages.
